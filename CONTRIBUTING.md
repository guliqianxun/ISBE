# Contributing

Issues and merge requests follow [docs/process.md](docs/process.md): every
update carries evidence from a real run (screenshots, CLI output, logs, test
output and the commands to reproduce it), and a separate reviewer reviews each
merge request before it is asked to merge.

To find your way around the code, read [docs/architecture.md](docs/architecture.md);
to run the tests, [docs/testing.md](docs/testing.md).

What a change is held to: [docs/standards/](docs/standards/README.md) has the
frontend and backend standards, the definition of done, and the review
standard with its reviewer roles and the checklist for closing an issue.
