# 当前工作论点

（这是 bootstrap 模板；正式论点应该从前几周观察 + 用户校准里慢慢沉淀。digester 的"蒸馏"段会持续输出 DRAFT 候选。）

- **2026 国产 AI 算力链**：H20 受限后国内 GPU（华为昇腾 / 寒武纪 / 沐曦 / 摩尔线程）进入实际批量客户验证阶段；密切跟踪客户名单与制程突破。
- **AI 应用层"金主"**：模型厂商（字节豆包 / 阿里通义 / 智谱 / Moonshot / DeepSeek）的 to-B 客户案例比起卷模型分数更重要。
- **出海第二波**：从纯白牌跨境（Temu / Shein）走向品牌出海（Anker / Insta360）+ 服务出海（SaaS / 餐饮）；要看品牌做深度还是广度。
- **机器人投资**：从财务投资转向战略投资（车厂 + 互联网厂商入股）；2026 是商业化前夜还是又一波泡沫，看订单 & 出货数据。
- **政策**：生成式 AI 备案数量 vs 实际可商业化的数量缺口大，期待今年是否出现强力扶持 or 进一步收紧。
