# 关注

- **赛道**：AI 应用 / 大模型公司动作、半导体（设计 / 设备 / EDA）、机器人、新能源 & 自动驾驶、出海（电商 / 制造）
- **事件类型**：融资轮 & 估值、IPO / 上市、并购、裁员 & 高管变动、新品发布、政策变化（国务院 / 工信部 / 美方制裁）
- **公司**：字节、阿里、腾讯、美团、拼多多、Shein、Temu、寒武纪、华为海思、地平线、寒武纪、深度求索、Moonshot、智谱、月之暗面、宁德、比亚迪等

# 不关注

- 纯股价 / 大盘行情播报（"恒指午盘涨 X"）
- 个股互动平台问答转载（"X 公司在互动平台表示…"，除非是关键澄清）
- 商务 / 招商类广告（VClub、入驻、报道申请）
- 单一区域低质量本地新闻（除非北上深江浙）

# 关注角度

- 一级市场水温（融资节奏、估值变化）
- 中美科技博弈对中国厂商的影响（出口管制 / 进口替代 / 出海路径）
- 头部公司战略调整（裁员 / 并购 / 业务剥离）
- 监管转向（生成式 AI 备案、数据出境、平台经济）
