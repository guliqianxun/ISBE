# 关注

- **排量段**：200cc - 1000cc 公路 / 街车 / 运动 / ADV / 复古
- **品牌**：Honda CB 系、Yamaha MT 系、KTM Duke、Triumph、Aprilia、Ducati 中量级
- **使用场景**：通勤 + 周末山路 + 偶尔 track day
- **价格区间**：5-15 万 RMB 等价段

# 不关注

- 哈雷 / 巡航复古重型（除非有重大技术变更）
- 踏板 / 电动滑板 / Sub-200cc 入门
- 单纯改装文化、咖啡馆复古风格

# 关注角度

- 新车发布（含改款 / mid-cycle update）
- 召回 / 重大安全更新
- 价格区间变化（年款上调 / 入门段挤压）
- 关键技术演进（电控套件、智能仪表、电子悬挂下放）
- 长测、二手保值对比
