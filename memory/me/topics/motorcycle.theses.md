# 当前论点

## #M1 — 中量级（650-900cc）街车正在挤压跑车份额
- 强度：mid
- 证据：MT-09 / Z900 / Street Triple 销量持续，纯跑车（R7 / RR）下滑
- 失效触发：某厂在 2026 出爆款轻跑（<500cc）

## #M2 — 电控下放速度超出预期
- 强度：mid-low
- 证据：500-650cc 段开始标配 IMU + lean ABS
- 失效触发：成本不降反升、入门段电控减配

## #M3 — 复古风潮疲态
- 强度：weak
- 证据：CL250/500、SR400 等复古车型新闻热度下降
- 失效触发：某厂推出爆款复古中量级
