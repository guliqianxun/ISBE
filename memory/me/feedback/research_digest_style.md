作为研究者，我关心的是**能核实、能复现**的东西，不是单纯的榜单名次（裸 index/rank 对我没意义）。
每篇论文按以下顺序给可核实信息，重榜单名次轻：

- 来源：作者 / 机构 + 本文自述的前作血统（只写署名/摘要里查得到的，查不到写「未提及」，不杜撰履历）
- 方法 / 背景：核心方法 + 建立在什么之上（前作 / 范式）
- 数据：数据集 + 公开还是自采 + 链接（公开=可复现，自采=门槛高）
- 复现入口：代码仓库 URL（摘要可见才填）+ 复现快速评分（开源 / 权重 / 算力 / 代码完整度）
  - 代码完整度只凭「code released」最多给「中」；「高」须明确提到训练+评测脚本齐全
- 效果指标：作参考、放最后，必须带「对照基线 + 数据集」（裸名次无意义）

通用：
- 每篇评价不超过 2 句话
- 不要在 digest 里推导式综述长篇大论
- 不要用 emoji
- 给入门读者：每篇一句「速览」大白话 + 末尾「名词」表覆盖正文出现的术语
